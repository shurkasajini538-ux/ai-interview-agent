## 保留与重写

| 参考中的价值 | 本版实现 |
|---|---|
| Word / PDF / 图片 / 文字导入 | DOCX 解包、PyMuPDF、本地 RapidOCR；无硬编码个人电脑路径 |
| 结构化信息展示 | 原文证据、技能、项目、明确学历，允许核对和编辑 |
| 可视化统计 | 简历库中的实际技能与学历统计，以及真实练习成绩 |
| 原项目的追问与评分 | 固定题目状态流程、逐题追问、补充回答、分项校验 |
| 原项目的 Memory | SQLite 中的历史回答与分项薄弱点，实际影响下一轮出题 |
| 原项目的回答优化 | 只重组回答原文的 STAR；缺失事实保持待补充 |

## 明确去掉

- 随机工作年限、随机画像标签和缺乏依据的薪资、招聘优先级。
- 等待几秒后读取固定 Excel 充当本次批量解析结果。
- 公开或硬编码 API Key / OCR Token。
- 必须依赖但未提供的定制模型目录。
- 仅导入框架就显示“已接入框架”的标签。
- 硬编码的项目成果、公司经历和性能数字。
- 用问题文本第一行推断题目、分项和总分不一致、共享临时简历文件。
