# 参赛产品范围

定位：本科生项目经历表达与事实核验的 AI 面试陪练。

核心路径：简历导入与核对 → 岗位和练习目标 → 证据检索 → 逐题回答与追问 → 有依据的评分 → 事实缺口与 STAR 整理 → 重答与历史复盘。

参赛主方向：AI 教育与学习平台。

本轮重点：受控 Function Calling、可追溯混合检索、事实保真、渐进式交互、React/TypeScript 工程、评测证据、可复现交付。

不把招生 / 招聘决策、薪资预测、人格或情绪判断作为产品功能。分数是练习反馈，不用于自动筛选求职者。

现有本机运行方式和历史记录保持兼容。公网演示与语音为可选扩展，不能影响核心提交版。参赛团队和来源说明必须真实，未知信息明确标记。

完成标准以 `参赛成品工作计划.md` 的交付判定为准；新能力通过验证后再标记完成。
