# 面试工坊试用方案与反馈表

状态：已准备方案，尚未招募或记录真实试用。不得把模拟验收结果当作学生效果研究。

## 参与与数据

由参赛队联系自愿参加的同学和教师。可以使用模拟简历；使用真实简历时先移除联系方式等不必要信息。记录使用目的、保存范围和退出方式，不将原始简历与回答公开到仓库。

## 任务

1. 导入并核对一份简历。
2. 选择熟悉的目标岗位，完成至少两题回答与追问。
3. 阅读评分依据和待补充事实，选择一题重新作答。
4. 导出报告，检查结果是否能指导下一次准备。

## 分析方法

统计实际样本量与任务完成率，汇总相关性和可执行性反馈，逐条记录事实错误和修复。样本小则报告描述性结果，不声称显著提升、普遍有效或替代教师评价。
